# Choosing a Programming Tool and Setup

An OpMode is a program that instructs the robot what to do. Three programming tools are available for creating OpModes; _FIRST_ strongly recommends that **all users begin by learning the Blocks programming tool**.

## The Blocks Programming Tool

A visual programming environment accessible via web browser for creating, editing, and saving OpModes. Suits novice programmers and those who prefer drag-and-drop visual design. "For many users (especially rookies and novice programmers), the Blocks Programming Tool is the best overall tool to use" — intuitive, easy to learn, and the fastest path to programming the robot. Needs only a web browser — works on iPads, Android phones, or Chromebooks.

### Blocks Tutorial Structure
1. **Introduction to Blocks** — Control System Introduction, Required Materials, Using Your Android Device.
2. **Configuring Hardware** — Configuring Android Devices, Connecting Devices to Control or Expansion Hub, Configuring Hardware.
3. **Connecting to Program & Manage Server** — Installing a JavaScript-Enabled Browser, Connecting a Laptop to the Program & Manage Network.
4. **Writing an OpMode** — Creating Op Modes, Running Your Op Mode, Managing Op Modes in Blocks, Controlling a Servo, Using Sensors.
5. **Reference Documents** — Blocks Reference Materials.

## The OnBot Java Programming Tool

A text-based web browser tool for creating, editing, and saving Java OpModes. Suggested for programmers with basic-to-advanced Java knowledge who want text-based OpModes rather than blocks. Resembles Blocks in workflow but requires solid Java understanding.

### OnBot Java Tutorial Structure
1. **Introduction** — Control System Introduction, Required Materials, Using Your Android Device.
2. **Configuring Your Hardware** — Configuring Android Devices, Connecting Devices To a Control or Expansion Hub, Configuring Your Hardware.
3. **Connecting to the Program & Manage Server** — Installing a JavaScript-Enabled Browser, Connecting a Laptop to the Program & Manage Network.
4. **Writing an Op Mode** — Creating and Running an Op Mode, Controlling a Servo, Using Sensors.
5. **Reference Documentation** — OnBot Java Reference Info.

## Android Studio

"An advanced integrated development environment for creating Android apps" — the same platform professional Android developers use. Recommended only for advanced users with extensive Java experience; it offers enhanced editing/debugging features unavailable in OnBot Java but requires significant learning investment and a dedicated laptop.

### Android Studio Tutorial Structure
1. **Introduction** — Control System overview, Required Materials, Using Your Android Device.
2. **Configuring Your Hardware** — Configuring Android Devices, Connecting Devices To a Control or Expansion Hub, Configuring Your Hardware.
3. **Installing Android Studio** — Installing Android Studio, Downloading the Android Studio Project Folder.
4. **Managing an Android Studio Project** — Fork and Clone from GitHub.
5. **Writing an Op Mode** — Enabling Developer Options, Creating and Running an OpMode, Controlling a Servo, Using Sensors.

Key resources referenced across all three tutorials: _FIRST_ Official Team Resources, Official Game Q&A, and FTC Programming Documentation.

## Recommendation Summary

- **Rookies / novice programmers** → Blocks (fastest path, easiest to learn, browser-only).
- **Basic-to-advanced Java programmers who want text code without an IDE** → OnBot Java (browser-only).
- **Advanced users with extensive Java experience wanting a full IDE** → Android Studio (requires a dedicated laptop and much more setup, but full editing/debugging power).
