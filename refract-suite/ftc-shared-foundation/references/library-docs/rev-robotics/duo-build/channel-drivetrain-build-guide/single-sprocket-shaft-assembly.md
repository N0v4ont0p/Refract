# Single Sprocket Shaft Assembly

### Single Sprocket Shaft Assembly Parts Required

| **PART NUMBER**                                         | **DESCRIPTION**              | **QTY.** |
| ------------------------------------------------------- | ---------------------------- | -------- |
| [REV-41-1323](https://www.revrobotics.com/rev-41-1323/) | 15MM SPACER                  | 1        |
| [REV-41-1324](https://www.revrobotics.com/rev-41-1324/) | 3MM SPACER                   | 2        |
| [REV-41-1326](https://www.revrobotics.com/rev-41-1326/) | THROUGH BORE BEARING - SHORT | 2        |
| [REV-41-1327](https://www.revrobotics.com/rev-41-1327/) | SHAFT COLLAR                 | 1        |

### Single Sprocket Shaft Assembly Steps

|                                  |                                                                                                                                                                           |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ![](/files/-Me1n2Q9gJTmGudf7Tyu) | <p>Add a Shaft Collar flush to the end of the 5mm x 90mm Hex Shaft.</p><p><br>Tighten the Shaft Collar.</p>                                                               |
| ![](/files/-Me1nerMvm19-uZEMZti) | <p>Slide a Through Bore Bearing – Short onto the shaft.</p><p>Note the smaller portion of the bearing faces towards the Shaft Collar.</p>                                 |
| ![](/files/-Me1o7iVnNe6SPJ-GEbm) | <p>Slide a 3mm Spacer onto the shaft.<br></p>                                                                                                                             |
| ![](/files/-Me1oqtf1rDlw2C8AzS6) | Slide a 10 Tooth # 25 Sprocket onto the shaft.                                                                                                                            |
| ![](/files/-Me1pQ8DMCt4kZHUzqmC) | Slide a 15mm Spacer onto the shaft.                                                                                                                                       |
| ![](/files/-Me1pm1byUMvGnq8qcZ_) | Slide a 3mm Spacer onto the shaft.                                                                                                                                        |
| ![](/files/-Me1qTUGzCp946ArT-X-) | <p>Slide a Through Bore Bearing – Short onto the shaft.</p><p>Note the smaller portion of the bearing faces away from the Shaft Collar.</p>                               |
| ![](/files/-Me1qfnB5vP-7u19w10K) | <p><strong>SINGLE SPROCKET ASSEMBLY COMPLETE</strong><br></p><p>Repeat the above steps until there are two completed Single Sprocket Assemblies. Set aside for later.</p> |
