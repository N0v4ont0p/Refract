### Drive Rail Assembly Steps

|                                                                     |                                                                                                                                                                                                                                                                                    |
| ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <img src="/files/-MG9vYAJQ3MYwnHo9_h8" alt="" data-size="original"> | <p>Place M3 Screws and M3 Lock Nuts in the correct locations. Tighten until nuts are snug.</p><p>Note: The Output Cartridge of the UltraPlanetary Gearbox lines up with the fourth large (9mm) hole from the end of the C Channel.</p>                                             |
| ![](/files/-Me2177jMrwEh3oS2Jn1)                                    | Attach a U Channel End Cap to the Motor end of the C Channel. Add three Hex Cap Screws to hold it in place. Tighten the Hex Cap Screws.                                                                                                                                            |
| ![](/files/-Me21QlVcQyqG5jB6kaR)                                    | Attach a U Channel End Cap to the other end of the C Channel. Add three Hex Cap Screws to hold it in place. Tighten the Hex Cap Screws.                                                                                                                                            |
| ![](/files/-Me5UlrJTlupADClDRj0)                                    | Align the Hex of the shaft with the UltraPlanetary Gearbox. Insert the Drive Shaft Assembly into the UltraPlanetary Female Hex output.                                                                                                                                             |
| ![](/files/-Me5V4WmSGNfJ-_yvVKc)                                    | Remove the Shaft Collar, Omni Wheel, and one Through Bore Bearing – Short from the Drive Shaft Assembly.                                                                                                                                                                           |
| ![](/files/-Me5VO4DvhQISv4CGGsV)                                    | Remove the Shaft Collar from the Single Sprocket Assembly. Set aside for use later.                                                                                                                                                                                                |
| ![](/files/-Me5Vei7tclFJ4LJfwuD)                                    | Remove the Shaft Collar from the end of the Double Sprocket Assembly. Set aside for use later.                                                                                                                                                                                     |
| ![](/files/-Me5ZqLgC5M5jWZzQNzi)                                    | Insert the Double Sprocket Assembly, short end towards the Motor, into the thirteenth large (9mm) hole from an End Cap.                                                                                                                                                            |
| ![](/files/-Me5_zr5FbZ3c_92KzX6)                                    | Add a Shaft Collar to the end of the shaft. Tighten down the set screw.                                                                                                                                                                                                            |
| ![](/files/-Me5aqXaZF2cf_gT1bWi)                                    | Insert the Single Sprocket Assembly, sprocket side toward the motor, into the fourth large hole from the non-Motor End Cap.                                                                                                                                                        |
| ![](/files/-Me5b8JEpj2eCzVDqkvt)                                    | Add a Shaft Collar to the end of the shaft. Tighten down the set screw.                                                                                                                                                                                                            |
| ![](/files/-Me5c-FLSgcFZZ-p-FLI)                                    | <p>Add four M3 Standoffs - 40MM along the C Channel for chain tension with M3 Hex Cap Screws. Add Tension Bushings onto each Standoff</p><p>Note: See the next step for locations.</p>                                                                                             |
| ![](/files/-Me5erzzrTOk53Cl9PRB)                                    | <p>Tighten down the Hex Cap screws once the Standoffs are in the correct locations towards the bottom of the slotted holes.</p><p>Note: Screws should be tightened just enough to hold the standoffs in place. Chain tension is adjusted later in the drive rail construction.</p> |
| ![](/files/-Me5fPxMIe_Q83cQnBSA)                                    | <p>Add the 56 Link Chain Loop to the Sprockets.</p><p>Note: Keeping the Standoffs with Tensioning Bushings loose can help getting the chain loops on the Drive Rails.</p>                                                                                                          |
| ![](/files/-Me5jcJQKPDFgJw7InfV)                                    | <p>Take a 45mm X 15mm C Channel – 408mm and seat the large holes on the bearings on each shaft.</p><p>Note: Make sure the bearings are square and the Channel End Cap holes line up.</p>                                                                                           |
| ![](/files/-Me5kdh2xhYQqE_Bet2A)                                    | Take ten Hex Cap Screws and secure the 45mm X 15mm C Channel – 408mm to the rest of the assembly. Screw into the End Caps and the Standoffs to keep the chain tensioned.                                                                                                           |
| ![](/files/-Me5lO7-t-6rgIxwW3w2)                                    | <p><strong>DRIVE RAIL ASSEMBLY COMPLETE</strong></p><p>Repeat this step until you have two Drive Rail Assemblies.</p>                                                                                                                                                              |

{% hint style="info" %}
You may need to go tension the chain on the drive rail. To do so, adjust the tensioning bushing up or down the slot they are fastened in to get the correct tension. See the [Chain Tension](/duo-build/motion/sprockets-and-chain.md#chain-tension) section for guidance.
{% endhint %}
