## Middle Grip Wheel Assembly Steps

|                                                                     |                                                                                                                                                                                                   |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <img src="/files/-MI622PFdgIZXcZMOFhT" alt="" data-size="original"> | Add an End Cap Bearing to the 135 mm x 5mm Hex Shaft.                                                                                                                                             |
| <img src="/files/-MI61ysk-oyOT7nlvO9k" alt="" data-size="original"> | Slide a 3mm Spacer onto the shaft.                                                                                                                                                                |
| <img src="/files/-MI61TaDzGQ8-LcqkJJA" alt="" data-size="original"> | Slide a 90mm Grip Wheel onto the shaft.                                                                                                                                                           |
| <img src="/files/-MI61QfduQsR1ZPmyTE4" alt="" data-size="original"> | Slide a 90 Tooth Plastic Gear onto the shaft.                                                                                                                                                     |
| <img src="/files/-MI61KgC_skmS2_rH-03" alt="" data-size="original"> | Slide a 15mm Spacer onto the shaft.                                                                                                                                                               |
| <img src="/files/-MI61DPPUvenARDeBAHT" alt="" data-size="original"> | Slide a 3mm Spacer onto the shaft.                                                                                                                                                                |
| <img src="/files/-MI5vDvDG2YfETnUC39U" alt="" data-size="original"> | Slide a Shaft Collar onto the shaft. Make sure the shaft collar is flush with the 3mm Spacer. Tighten the set screw.                                                                              |
| <img src="/files/-MI5v9NeB5oS7WCIdo_5" alt="" data-size="original"> | <p>Slide a Through Bore Bearing - Long onto the Shaft.</p><p><strong>Note:</strong> the longer portion of the bearing faces away from the Shaft Collar.</p>                                       |
