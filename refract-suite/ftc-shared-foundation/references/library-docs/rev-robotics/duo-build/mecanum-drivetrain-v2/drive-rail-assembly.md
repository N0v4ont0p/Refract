### Motor Pod Assembly Steps

#### Ultra 90 Degree Gearbox Installation

| Image                            | Description                                                                                                                                                                                                                                           |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ![](/files/6OVt9pa6acT8wYqvjukB) | Insert the 20mm long hex shaft into the output of the gearbox.                                                                                                                                                                                        |
| ![](/files/DfL2wUZFx3EEuVjWU5r8) | <p>Place the Face Mount Spacer on the output of the the gearbox as shown. </p><p></p><p><strong>Note: Line up the short edge of the spacer with a flat side of the UltraPlanetary gearbox body.</strong></p>                                          |
| ![](/files/HwvWisYAmcYuWVGFvUNa) | Rotate the hex shaft output so that it lines up with the hex input on the Ultra 90 Degree Gearbox.                                                                                                                                                    |
| ![](/files/s9xBpQRd37kg7uKEpC8l) | Slide the two gearboxes together. Rotate the Ultra 90 Degree Gearbox until the spacer and gearbox body line up.                                                                                                                                       |
| ![](/files/Qex4p342vben3pHLHBfn) | Insert the 4 mounting screws in the holes on the end of the Ultra 90 Degree Gearbox. Ensure that they line up with the holes in the spacer and the gearbox.                                                                                           |
| ![](/files/w7LLck7tmNKHBe8Bngma) | <p>Tighten the 4 mounting screws hand-tight. Then alternate between slightly tightening screws diagonally across from each other in an X shaped pattern. </p><p></p><p><strong>Note: Take care not to over tighten the mounting screws.</strong> </p> |

Make 2 of the Right Wheel Shaft assembly<br><br>- 3mm Spacer (Or 2 - 1.5mm Spacers)<br>-15mm Spacer<br>-Right 75mm Mecanum Wheel<br>-Shaft Collar<br><br>The Shaft Collar should be flush with the right side of the Hex Shaft.</p> |
| ![](/files/R6Y8nJaL8p5wNPgUmIbV) | <p>Slide the following onto a 90mm long 5mm Hex Shaft. | ![](/files/7HtkokuIIUiLN6tY4RLU) | <p>Fasten 2 Motor Pod Assemblies with 16 - M3 6mm Hex Head Screws total in between two pieces of C Channel<br><br>The output of the Ultra 90 Degree Gearbox will line up with the 2nd large (9mm) hole from each end of the C Channel</p>                                                  |

{% hint style="warning" %}
The Ultra 90 Degree Gearbox should have 4mm of thread engagement with each screw. If you do not have 6mm screws to use for your assembly, please use washers or a spacer of approximately 2mm thickness on the outside of the C Channel.
{% endhint %}
