### Drive Rail Assembly Steps

|                                                                     |                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <img src="/files/-MG9vYAJQ3MYwnHo9_h8" alt="" data-size="original"> | <p>Attach an UltraPlanetary Assembly to a 45mm x 15mm C Channel - 408mm. Place M3 Screws and M3 Lock Nuts in the correct locations. Tighten until nuts are snug.</p><p></p><p><strong>Note:</strong> The Output Cartridge of the UltraPlanetary Gearbox lines up with the fourth large (9mm) hole from the end of the C Channel.</p>   |
| <img src="/files/-MG9hU--PrMD6nyvl_VT" alt="" data-size="original"> | <p>Attach an UltraPlanetary Assembly to a 45mm x 15mm C Channel - 408mm. Place M3 Screws and M3 Lock Nuts in the correct locations. Tighten until nuts are snug.</p><p></p><p><strong>Note:</strong> The Output Cartridge of the UltraPlanetary Gearbox lines up with the thirteenth large (9mm) hole from the end of the Channel.</p> |
| <img src="/files/-MMMm6BmtneiBG-NICYu" alt="" data-size="original"> | <p>Attach a Hex Bearing Block to a 45mm x 15mm C Channel - 408mm using M3 x 8mm Screws. Tighten until screws are snug. </p><p></p><p><strong>Note:</strong> The Hex Bearing Block lines up with the Forth large (9mm) hole from the end of the Channel.</p>                                                                            |
| <img src="/files/-MG9bt1R-BbzWWJn8_ub" alt="" data-size="original"> | Attach a U Channel End Cap to the Motor end of the C Channel. Add three Hex Cap Screws to hold it in place. Tighten the Hex Cap Screws.                                                                                                                                                                                                |
| <img src="/files/-MMMEOZSOCfDWvXY-CCF" alt="" data-size="original"> | Attach a U Channel End Cap to the other end of the C Channel. Add three Hex Cap Screws to hold it in place. Tighten the Hex Cap Screws.                                                                                                                                                                                                |

{% hint style="info" %}
In the following section 5mm Hex Shafts will be placed on the Drive Rail. This is be doing to get correct spacing on the Shafts. However the Shafts will not be be secure until the end of the assembly and may come loose during the building process.&#x20;
{% endhint %}

|                                                                     |                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| <img src="/files/-MMMeDK9jRZHSwQHO0jt" alt="" data-size="original"> | Add a 75mm Hex Shaft to the second motor on the Drive Rail.                                                                                                                                                                                                                                                                                                                                                  |
| <img src="/files/-MMMeVIDUr7s7EJg9uOB" alt="" data-size="original"> | Add a 90mm Hex Shafts to the first motor and the Hex Bearing Block                                                                                                                                                                                                                                                                                                                                           |
| <img src="/files/-MMMepFZB2vEa2VjVToF" alt="" data-size="original"> | Add three 3mm Spacers the 75mm Hex Shaft that is on the second motor.                                                                                                                                                                                                                                                                                                                                        |
| <img src="/files/-MMMIQJ3QVaw75owcgvP" alt="" data-size="original"> | Add two 24 Tooth GT2 3mm Pitch Pulleys to the shaft on the second motor and the Hex Bearing Block Shaft.                                                                                                                                                                                                                                                                                                     |
| <img src="/files/-MMMcaWxkoN9acdpf8XQ" alt="" data-size="original"> | <p>Add Shaft Collars to all three Hex Shafts. Do not tighten any of the shaft collars. </p><p></p><p><strong>Note:</strong> At this point nothing has been added to put space between the first motor and the Shaft Collar. This Shaft Collar can be adjusted after the second C Channel is placed. In general it is better to situate the shaft collar away from the motor to make adjustments easier. </p> |
| <img src="/files/-MMMcvPZyMibXz5coNhz" alt="" data-size="original"> | <p>Add Through Bore Bearings - Short to all three Hex Shafts. </p><p></p><p><strong>Note:</strong> the smaller portion of the bearing faces away from the Shaft Collar.</p>                                                                                                                                                                                                                                  |
| <img src="/files/-MMMbx2aNj-K_AjZwlaU" alt="" data-size="original"> | Add 3mm Spacers to all three Hex Shafts.                                                                                                                                                                                                                                                                                                                                                                     |
| <img src="/files/-MMMU_h-iHxKU3baiOwq" alt="" data-size="original"> | <p>Slide the 120 Tooth GT2 3mm Pitch Belt onto the Pulleys. </p><p></p><p><strong>Note:</strong> The easiest way to add the Belt to the assembly is to remove either the second motor shaft or the Hex Bearing Block Shaft. Hook the Belt over both Pulleys so that the teeth of the Belt are meshed with the Pulley. Then replace the displace shaft to its original position. </p>                         |
| <img src="/files/-MMMcQRJDGQAMRAO4xL9" alt="" data-size="original"> | <p>Add Hex Bearing Blocks to all three shafts. </p><p></p><p><strong>Note:</strong> The Hex Bearing Blocks will rotate on the shafts. This is fine but for the next step they need to be oriented as shown in the image. </p>                                                                                                                                                                                |
| <img src="/files/-MMMZy4-kD7as1J1i0oL" alt="" data-size="original"> | <p>Add a Channel – 408mm to close out the Drive Rail. </p><p></p><p><strong>Note:</strong> Make sure the Bearing Blocks are square and the Channel End Cap holes line up.</p>                                                                                                                                                                                                                                |
| <img src="/files/-MMMarAr7ZvVTw1XaC5u" alt="" data-size="original"> | Take eighteen 8mm Hex Cap Screws and secure the 45mm X 15mm C Channel – 408mm to the rest of the assembly. Screw into the End Caps and the Bearing Blocks to keep everything in place.                                                                                                                                                                                                                       |
| <img src="/files/-MMMfz4Hu4_6uw5IxOhg" alt="" data-size="original"> | <p><strong>DRIVE RAIL ASSEMBLY COMPLETE</strong></p><p>Adjust Shaft Collars and tighten set screws. </p><p></p><p>Repeat these steps until you have two Drive Rail Assemblies.</p>                                                                                                                                                                                                                           |
