# Pinion Removal Guide

### HD Hex Pinion Pressing Guide

#### Needed Materials:

* HD Hex Motor (REV-41-1291) With Pinion Pressed On
* A Small Flathead Screwdriver
* Hex Shaft For Leverage (or similar)
