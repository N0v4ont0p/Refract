# L Beam

## L Beam Basics

[L Beams ](https://www.revrobotics.com/competition/ftc/structure/channel/)are a structural element for small load applications or as a supporting component on a larger load application. They’re compact and lightweight and provide more strength than a[ Flat Beam](https://www.revrobotics.com/competition/ftc/structure/channel/). Use them to create a corner between plates, attach channel to extrusion, or for fastening your own creations.
