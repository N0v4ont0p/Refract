# Control Hub

## Connecting Via USB

| Steps                                                                                                                                                                              |                                                                                                                                                      |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Power on the Control Hub, by plugging the 12V Slim Battery ([REV-31-1302](https://www.revrobotics.com/rev-31-1302/)) into the XT30 connector labeled “BATTERY” on the Control Hub. | <img src="/files/-MGiwd2_jEdNOT9zicgN" alt="C:\Users\Rachel\AppData\Local\Microsoft\Windows\INetCache\Content.Word\g20714.png" data-size="original"> |
| The Control Hub is ready to connect with a PC when the LED turns green. Note: the light blinks blue every \~5 seconds to indicate that the Control Hub is healthy.                 | ![C:\Users\Rachel\AppData\Local\Microsoft\Windows\INetCache\Content.Word\rect22073.png](/files/-MGiwhWE2P1bncBuUYrP)                                 |
| Plug the Control Hub into the PC using a USB-A to USB-C Cable ([REV-11-1232](https://www.revrobotics.com/rev-11-1232/))                                                            |                                                                                                                                                      |

Startup the REV Hardware Client. Once the Hub is fully connected it will show up on the front page of the UI under the Hardware Tab. Select the Control Hub.&#x20;
