# Firmware Changelog

### **Version 1.8.2 (Latest Version)**

* Improved USB recovery in case of fault event (e.g. ESD fault)
* Improved DC motor output linearity
* Improved closed-loop control modes
* Improved I2C speeds
* Minor bug fixes&#x20;
