# Bill of Materials

The 2025-26 REV DUO Starter Bot is designed to be built using the FTC Starter Kit V3.1 ([REV-45-3529](https://www.revrobotics.com/rev-45-3529/)) and DUO Control Bundle ([REV-35-2709](https://www.revrobotics.com/rev-35-2709/)).

{% hint style="info" %}
Please note that if you purchased your FTC Starter Kit V3.1 before the summer of 2025, you will need to purchase the following:

* QTY 1 - [5mm Hex Bearing Block (REV-41-1683)](https://www.revrobotics.com/rev-41-1683/)
  {% endhint %}
