# BeeLine Chassis Kit — Assembly Guide

SKU: 3209-0002-0001. A belt-driven drop-center drivetrain: two motors per side drive a shared 8mm REX™ shaft cluster through GT2 timing belts and pulleys, powering a front Omni wheel and a rear Rhino wheel per side (four wheels total, drop-center configuration). The two side sub-assemblies are mirror images joined by crossbars.

Build one side, then mirror it for the other side (Step 20 explicitly repeats steps 2–21 for the second side).

## Steps 1–3 — Crossbars, motor mounting, pinion gears

1. Fasten a Quad Block Mount to each end of both 10-Hole U-Channels using eight 11mm screws (these are the crossbars).
2. Mount one 312 RPM Yellow Jacket motor to the 10th hole from the end of a 17-Hole U-Channel, and a second motor to the 12th hole from the end, each with eight 11mm screws.
3. Put a 30-Tooth, 6mm D-Bore steel pinion gear on each motor's output shaft (leave set screws loose for now).

## Steps 4–8 — Center shaft & gear cluster

4. Insert an 8mm REX bearing into the 14mm hole between the two motors (flange facing inside the channel). Slide a 60mm 8mm REX shaft into it from between the motors, add a shim against the bearing's flanged side, then a 30-Tooth 8mm REX-bore gear (set screws loose).
5. Slide an 8mm-ID spacer onto that shaft, pushed back flush.
6. Loosely drape a 64-Tooth timing belt over the gear cluster. Add another bearing to the hole directly opposite the center shaft (flange inward); a spare shaft can be temporarily used as an alignment tool while stacking a spacer onto it.
7. Insert a 16-Tooth pulley between the spacers, then push the shorter 8mm REX shaft through the pulley — this pushes the temporary alignment shaft out. Push the permanent shaft flush with the far bearing.
8. Tighten the pulley's set screws, then the 8mm REX-bore gear's set screws. Align the pinion gears on the motor shafts with the center shaft's gear and tighten those set screws too.

## Steps 9–10 — Drop-center plate bearings

Mount Drop-Center Plates (triangle markings facing the channel's open side) to the 2nd and 16th holes of the U-Channel using 14mm screws, washers, and locknuts, adding an 8mm REX bearing to each drop-plate's 14mm hole.

## Steps 11–16 — Front and rear driven shafts

11. Wrap the belt from Step 6 around a 16-Tooth pulley; pass an 88mm 8mm REX shaft through bearing → pulley → far bearing.
12. Add a shim then a Sonic Hub onto that shaft; push fully in and tighten pinch bolts.
13. In the 9th hole, build a similar assembly (bearing, spacer, pulley, shim, bearing) using the longer 420mm belt and an 8mm REX shaft with a snap ring — slide the shaft through until the snap ring bottoms against the bearing's inner race.
14. Add a 16-Tooth pulley to the 420mm belt and slide an 88mm shaft through the far bearings/pulley.
15. Add a shim and a Hyper Hub to that shaft (E-clip bottomed against the bearing), tighten the hub's pinch bolts, and align this pulley with the center pulley using the U-Channel's holes as a visual guide.
16. Add a spacer and Hyper Hub to the center shaft, tighten pinch bolts.

## Step 17 — Belt tensioning idler

Slide a Timing Belt Idler over a 43mm standoff and insert it into the channel to add tension to the belt (snug but able to turn freely). goBILDA shows a recommended idler placement (108mm reference dimension in the source diagram).

## Steps 18–19 — Standoffs & wheels

Add a standoff to each bottom corner hole of the channel using 11mm screws. Attach Rhino wheels to the two Hyper Hubs (deep side facing the chassis) using 18mm screws and washers; attach Omni wheels with a pattern spacer to the Sonic Hub using 30mm screws and washers. Clock the Omni wheels so the rollers of one coincide with the gaps of the other.

## Steps 20–22 — Mirror side & final assembly

Repeat Steps 2–21 to build the mirror-image second side. Attach the Step 1 crossbars to one side using 8mm screws, then attach the other side to the far end of the crossbars to complete the drivetrain.
