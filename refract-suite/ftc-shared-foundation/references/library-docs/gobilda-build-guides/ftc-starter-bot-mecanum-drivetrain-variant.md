# FTC Starter Bot with Mecanum Wheels (for DECODE™) — variant delta

This is goBILDA's mecanum-drive variant of the FTC Starter Bot. The assembly is **step-for-step identical** to the standard chain-driven Starter Bot documented in `ftc-starter-bot-full-build.md` (same 53-54 step sequence, same frame, chain drive, ramps, Gecko® Wheel intake, guideplates, and electronics mounting) — this file only records the delta so content isn't duplicated. Refer to that file for the full build; only the parts below differ.

## What's different

Built from:
- 1x FTC Starter Kit (SKU: 3200-4008-2526) — same as the standard build
- 1x Strafer® Chassis (SKU: 3209-0001-0007) — supplies the mecanum wheels
- 2x Flat Pattern Mount (SKU: 1222-0001-0001)

Everything through Step 50 (drivetrain frame, chain-and-sprocket drive, battery mount/upper frame, shaft/pushplate subassembly, ramps, second-motor conversion + hogback arm, Gecko® Wheel intake, guideplates) is unchanged from the standard build.

**Step 51 (final drivetrain wheels) is replaced:**
- Standard build: two Hogback Wheels + two Omni Wheels (eight 12mm Socket Head Screws + eight washers).
- Mecanum build: two Right-Slant Mecanum Wheels and two Left-Slant Mecanum Wheels, mounted using sixteen washers and sixteen 12mm Socket Head Screws. Mount the wheels to the Hub-Shafts from the wheel's "shallow" side. Check wheel-slant orientation carefully: correctly assembled, the rollers on all four wheels point diagonally outward from the robot's center when viewed from above.

Steps 52–53 (zip-tying the REV Control Hub, installing the 12V battery) are unchanged, just renumbered (53→52, 54→53 in this document's page count, since one drivetrain step's sub-figures collapse to a single step).

## Result

Same chassis, chain drive, and intake mechanism as the standard Starter Bot, but running on a 4-wheel mecanum (strafing) drivetrain instead of the compact Hogback/Omni wheel combination.
