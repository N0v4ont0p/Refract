# Strafer Chassis Kit V5 — Assembly Guide

SKU: 3209-0001-0005. A compact **mecanum drivetrain** chassis where each wheel is driven through a right-angle miter-gear pair rather than a motor mounted directly in-line with the wheel shaft — this lets all four drive motors sit inside the chassis frame facing the same direction.

## Step 1 — Chassis frame assembly

Attach four Quad Block Mounts to the ends of the two 10-Hole U-Channels using sixteen 11mm screws — these channels become the chassis "crossbars." Fasten the crossbars to the two 17-Hole U-Channels at holes 2 and 9 using sixteen 8mm screws. Before installing the crossbar at hole 2, place two 6mm ID flanged bearings into the channel holes at that position, noting their orientation.

## Step 2 — Output shaft assemblies

Build the four driven-wheel corner assemblies (one per corner): a Hub-Shaft passes through an 8mm ID flanged bearing and a 6mm ID flanged bearing, with a Miter Gear on the shaft, secured with a 10mm screw and washer. Duplicate this at all four corners.

## Step 3 — Constrain miter gears

Slide each Miter Gear as far toward the outside of the chassis as it will go (closest to the Hub-Shaft's mounting face, stopping just before it contacts the channel wall), then tighten both set screws with a 2.5mm hex key. Repeat at all four corners.

## Step 4 — Motor assembly

Mount a motor to a Quad Block using four 11mm screws. Add three 0.5mm shims onto the motor shaft (these let you fine-tune miter gear mesh later), then a 12mm spacer and a Miter Gear — slide everything down as far as it goes and tighten the Miter Gear's set screws. Repeat to build four Motor Assemblies total.

## Step 5 — Install motor assemblies

Install each Motor Assembly into the channel so its Miter Gear meshes with the corresponding corner's Miter Gear from Step 3. Secure with 11mm screws.

## Step 6 — Wheels

Fasten the mecanum wheels to the Hub-Shafts using sixteen 11mm screws (each with a washer). Each side of the robot gets one left-slant and one right-slant wheel. Each wheel core has a shallow side and a deep side — the deep side faces outward (away from the chassis). The chassis is typically assembled upside-down for visibility; once flipped right-side-up, the wheel rollers should point toward the chassis center when viewed from above.

## Tuning notes (from goBILDA's guide)

- The kit includes four Bullet-to-JST VH adapter cables for driving the chassis directly from a REV Robotics motor controller.
- With the battery disconnected, spin each wheel by hand — it should rotate smoothly. A small amount of backlash between the miter gears is desirable; if a wheel feels tight/high-friction, remove one shim from that corner's motor assembly (Step 4).
- Each Hub-Shaft ships with a 6mm ID, 0.25mm-thick shim to adjust bearing spacing if the Hub-Shaft has front-to-back play in the channel while its screw is fully tight — install the shim under the washer, aligned to the round portion of the Hub-Shaft.
