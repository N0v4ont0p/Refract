# Hammerhead Chassis — Assembly Guide

SKU: 3209-0003-0001. A boxed, panel-enclosed 4-wheel drivetrain chassis (Hurricane wheels/tires) with a fully enclosed electronics compartment — top plate, door, door surround, and side panels bolt onto a U-channel frame, and a goTUBE crossmember runs wiring through the box via an open goRAIL.

## Step 1 — Cross-bars

Attach two Quad Block Pattern Mounts to a 9-Hole U-Channel using eight 11mm screws, mounted one hole down from the channel edge. Repeat for a second identical "cross-bar" assembly.

## Step 2 — Frame

Attach a Quad Block Pattern Mount to the end of the remaining (unused) 9-Hole U-Channel using four 11mm screws, then attach that assembly to one of the cross-bars using four 8mm screws. This forms the chassis frame.

## Step 3 — Dual block mounts

Attach two 1-2-style Dual Block Mounts to the frame with four 11mm screws — note the orientation of the Dual Block Mounts carefully.

## Step 4 — Top plate

Attach the top plate to the frame using four 8mm screws, two 10mm screws, and two 14mm screws (each with a washer).

## Step 5 — Pillow blocks

Mount the two 32mm-bore pillow blocks using eight 8mm screws, oriented so the sides without the black ring face each other. Attach a Dual Block Mount using two 11mm screws.

## Step 6 — Standoffs

Attach ten 48mm-length standoffs to the top plate using 11mm screws (each with a washer).

## Step 7 — Door

Install four door latch assemblies using 20mm screws (each with a washer). Install the door into the door frame by rotating each door latch out of the way.

## Step 8 — Bottom panel

Secure the bottom panel assembly to the chassis using ten 11mm screws and two 10mm screws (each with a washer).

## Step 9–10 — goTUBE crossmember

Fasten the goTUBE Endcap to the 48mm goTUBE using four 14mm screws (each with a washer), then slide three 32mm ID black plastic spacers onto it. Insert the goTUBE assembly into the 32mm ID pillow blocks from inside the chassis, then slide a 32mm ID, 6mm-length aluminum spacer onto the protruding end.

## Step 11–12 — Second cross-bar and wiring pass-through

Attach two 43mm standoffs to the unused cross-bar using four 11mm screws. Mount the 43mm Open goRAIL inside the channel using eight 11mm screws (one screw is pre-placed loose to make the next step easier). Attach this cross-bar to the goTUBE assembly using four 11mm screws. The Open goRAIL's open side is oriented to face the channel's open side, letting motor wiring run from the motors into the enclosed box.

## Step 13–14 — Motors

Slide clamping mounts onto each of the four gear motors (first mount tightened against the motor now, second left loose). Attach the motor assemblies to the cross-bars' Quad Block Pattern Mounts using sixteen 11mm screws, then tighten the previously-loose clamping mount pinch bolts.

## Step 15–16 — Wheels

Fasten a Hyper Hub to each Hurricane Wheel using four 14mm screws (each with a washer) — the hub goes on the wheel's shallower side. Add a Leopard Tire to each wheel (four wheel assemblies total). For each motor, slide an 8mm ID, 6mm-length aluminum spacer onto the output shaft, then the wheel assembly, and tighten the Hyper Hub pinch bolts. goBILDA recommends gluing tires to the Hurricane rims and letting the glue cure 24 hours before use.
